# Статусы записей

| Статус | Что означает | Чего не означает |
| --- | --- | --- |
| `official` | Ответ прямо опубликован Wyrd | Не обязательно полный текст источника |
| `raw` | Вывод следует из буквального текста правил | Не официальный FAQ и не заявление о замысле автора |
| `community` | Локальная договорённость с областью действия | Не универсальное правило Malifaux |
| `disputed` | Есть несколько обоснованных трактовок | Не готовый ответ для турнира без решения организатора |

Если новый официальный материал меняет запись, установите `superseded` в `true`, добавьте ссылку на заменяющую запись и сохраните старую страницу для истории.

## Состояние текста карточки

Эти значения не заменяют основной статус ruling, а дополняют его.

| `app_card_status` | Значение | Отображение |
| --- | --- | --- |
| `potentially_stale` | FAQ меняет текст, но исправление не найдено в проверенной Errata | 🔴 Читать по FAQ |
| `assumed_current` | Исправление включено в официальную Errata; приложение считается обновлённым | 🟢 Дополнительных действий нет |
| `confirmed_stale_after_errata` | Будущий исключительный случай: Errata вышла, но приложение подтверждённо показывает старую карточку | 🔴 Читать по Errata |

Статус `confirmed_stale_after_errata` устанавливается только после отдельной проверки конкретной карточки.
