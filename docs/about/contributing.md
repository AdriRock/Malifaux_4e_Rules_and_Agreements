# Как помочь

Перед отправкой проверьте:

- статус не завышен;
- у записи есть стабильный уникальный ID;
- указаны версия и точный раздел источника;
- официальный текст не скопирован целиком;
- итог отделён от рассуждений;
- добавлены перекрёстные ссылки;
- заполнены `last_reviewed` и `superseded`.

Для предложения используйте GitHub issue по шаблону **Ruling proposal** или pull request.
