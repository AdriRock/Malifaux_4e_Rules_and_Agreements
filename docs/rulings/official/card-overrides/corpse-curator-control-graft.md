# Corpse Curator — Control Graft

!!! danger "Читать по FAQ"
    Для Control Graft используется исправленная последовательность из FAQ.

## Как следует играть

1. Выберите целью союзника с Graft Token.
2. Цель объявляет Action, напечатанный на её Crew Card, не снимая Graft Token.
3. Если объявлен **“New Arms!”**, можно объявить дополнительный Interact Action.
