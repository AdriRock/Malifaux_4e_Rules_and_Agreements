# Kara — Catlike Reflexes

!!! danger "Читать по FAQ"
    Ability имеет ограничение once per activation и проверяет elevation дружественной модели.

## Как следует играть

Один раз за активацию, когда дружественная модель завершает Move в пределах 6" и на elevation 2 или выше, Kara может разместиться в base contact с этой моделью.
