# Tara, Voidcaller — Adrift In Time

## Итог

Tara не может использовать **Adrift In Time**, если все остальные дружественные модели уже активировались: должна оставаться хотя бы одна другая дружественная модель, которая ещё может активироваться.

Использование способности не даёт игроку две последовательные активации. Активируется только Tara. Выбранная другая дружественная модель сохраняет возможность активироваться позднее, после того как соперник получит возможность провести свою активацию.

## Вопросы, закрытые FAQ

1. Можно ли применить способность, когда все дружественные модели уже активировались? Нет.
2. Следует ли сразу после Tara активация другой дружественной модели? Нет.
