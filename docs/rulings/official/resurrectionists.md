# FAQ: Resurrectionists

## 12.1 — Tormented: Set Adrift и Scream of the Lost

Вражеская модель с **Set Adrift**, контролируемая моделью банды Jack Daw, не может быть убита своим **Scream of the Lost**. Контролирующий противник не может выбрать вариант, убивающий эту модель, в том числе когда у неё нет подходящих ресурсов для альтернативы, согласно **This or That**.

## 12.2 — Ikiryo, Spirit of Vengeance: Death Curse

Новое в June 2026. Ikiryo можно контролировать через Obey так, чтобы она убила себя посредством **Death Curse**: её гибель не является Cost и не является выбором **This or That**.

## 12.3 — Gokudo: Greedy Token и Demise

Новое в June 2026. Gokudo без Reliquary Upgrade не может сбросить Greedy Token для использования своей Demise Ability.

## 12.4 — Zoraida, Crooligan и Rabble Riser

Новое в June 2026. Если Zoraida одного игрока контролирует Crooligan другого игрока и тот убивает союзного Rabble Riser, никто не получает kill credit, поэтому никто не сбрасывает карту и никто не погибает от Demise Rabble Riser.
