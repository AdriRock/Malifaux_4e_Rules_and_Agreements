# FAQ: Guild

## 9.1 — Уникальность Dashel Barker

**Dashel Barker, The Old Guard** и **Dashel Barker, Butcher** являются Unique Models.

## 9.2 — Domador de Cadáveres: Command Corpse

Новое в June 2026. Если **Command Corpse** создаёт другой Signature Action, исходный Action не становится этим Action и не приобретает его тип. Сначала полностью разрешается Command Corpse, затем созданный Action.

## 9.3 — Charles Hoffman, Inventor: Pylon Marker

Новое в June 2026. Если создание шестого Pylon Marker вынуждает удалить один из-за лимита, удалённый Marker создаёт свой эффект «when removed».

## 9.4 — Несколько Familia Tokens

Новое в June 2026. Одну порцию урона нельзя уменьшить несколькими Familia Tokens: модель не может одновременно подвергаться действию двух или более одноимённых Abilities, Tokens или Markers.
