# Kara

!!! danger "Текст карточки требует исправления"
    Для Kara есть два важных изменения чтения карточки.

- [Catlike Reflexes](../../rulings/official/card-overrides/kara-catlike-reflexes.md) — once per activation и условие elevation.
- [Springing Strike / «on Ht 2 terrain»](../../rulings/official/card-overrides/kara-springing-strike.md) — требуется elevation 2+, а не просто Terrain с Ht 2.

## Оригинальные формулировки FAQ

### Catlike Reflexes

> Please read this ability as if it said: Once per activation. When a friendly model ends a move within 6" and at elevation 2 or higher, this model may place into base contact with the friendly model.

[Официальный FAQ — Ten Thunders, ID 101](https://malifauxrules.com/rules/faq/101-ten-thunders)

### Springing Strike / «on Ht 2 terrain or higher»

> Read these rules as if they require the model to be “at elevation 2 or higher.” No, Kara will not receive a [positive] when targeting a model that is in a Ht 2, non-climbable fog bank.

`[positive]` обозначает напечатанный в FAQ значок положительного модификатора.

[Официальный FAQ — General, ID 43](https://malifauxrules.com/rules/faq/43-general)
