# Malifaux Community Rulings

База пояснений по правилам Malifaux 4E, подготовленная для публикации через MkDocs Material и GitHub Pages.

## Принцип базы

Записи разделены по статусу:

- `official` — ответы, прямо опубликованные Wyrd, например в FAQ или Errata;
- `raw` — вывод из буквального текста правил, не являющийся официальным FAQ;
- `community` — явно зафиксированная локальная договорённость;
- `disputed` — вопрос без принятого единого ответа.

Каждая запись имеет стабильный `id`, сведения об источнике и версии, ссылку на раздел, темы, дату проверки и поле `superseded`.

Официальные PDF не хранятся в этом репозитории. Страницы базы дают краткое изложение и библиографическую ссылку на источник.

## Локальный запуск

```bash
python -m pip install mkdocs-material
mkdocs serve
```

Сайт будет доступен по адресу, который выведет MkDocs (обычно `http://127.0.0.1:8000`).

## Публикация

Workflow `.github/workflows/deploy.yml` собирает и публикует сайт в GitHub Pages при изменениях в ветке `main`. В настройках репозитория GitHub Pages выберите источник **GitHub Actions**.

## Добавление записи

1. Выберите каталог, соответствующий статусу записи.
2. Скопируйте `docs/rulings/template.md` и заполните metadata.
3. Добавьте ссылки со страниц связанных моделей, банд и общих правил.
4. Откройте pull request или issue по готовому шаблону.

Перед публикацией замените placeholder в `LICENSE` на осознанно выбранную лицензию.
